# GameTimer — Техническое задание v1.0

> Десктопное WPF-приложение для родительского контроля: визуальный таймер поверх игр с обратным отсчётом, звуковыми уведомлениями и защитой паролем.

## Метаданные

- **Платформа:** Windows 10/11
- **Стек:** .NET 8 LTS · WPF · C#
- **Публикация:** single-file self-contained exe (win-x64)

---

## 01. Архитектура приложения

Приложение состоит из двух WPF-окон в одном процессе: главное окно (панель управления с настройками) и оверлей (безрамочное прозрачное окно с обратным отсчётом).

### ARCH-01: Два окна, один процесс
Главное окно и оверлей работают в одном процессе. Оверлей создаётся при запуске таймера и живёт до его завершения или отмены. Закрытие главного окна сворачивает приложение в трей, таймер продолжает работать.

### ARCH-02: Хранение настроек
JSON-файл рядом с exe (`settings.json`). Сериализация через `System.Text.Json`. Настройки загружаются при старте и сохраняются при каждом изменении. Никаких внешних зависимостей.

### ARCH-03: Публикация
Single-file self-contained exe: `dotnet publish -r win-x64 --self-contained -p:PublishSingleFile=true`. Не требует установленного .NET на машине.

## 02. Настройка таймера

### TMR-01: Два режима задания времени
- **Абсолютное время** — выбор часа и минуты (например, «выключить в 20:00»). TimePicker или два NumericUpDown (часы 0–23, минуты 0–59).
- **Интервал** — от текущего момента (например, «через 1 час 30 минут»). Два поля: часы (0–12) и минуты (0–59).

### TMR-02: Действие по истечении
Настраиваемое действие, выбирается в настройках через ComboBox:
- Выключение компьютера: `shutdown /s /t 0`
- Блокировка экрана: `rundll32 user32.dll,LockWorkStation`
- Выход из учётной записи: `shutdown /l`

По умолчанию — выключение.

### TMR-03: Управление таймером
Кнопки «Старт», «Стоп», «Сброс». Старт запускает обратный отсчёт и показывает оверлей. Стоп и Сброс защищены паролем (см. SEC-01). При отмене таймера с действием «выключение» вызывается `shutdown /a`.

---

## 03. Оверлей

Безрамочное WPF-окно, показывающее оставшееся время. По умолчанию — правый верхний угол экрана.

### OVR-01: Свойства окна
`WindowStyle=None`, `AllowsTransparency=True`, `Background=Transparent`, `Topmost=True`, `ShowInTaskbar=False`. Окно не появляется в Alt+Tab (через `WS_EX_TOOLWINDOW`).

### OVR-02: Click-through (прозрачность для событий)
Оверлей не перехватывает клики мыши — реализация через Win32 extended style `WS_EX_TRANSPARENT` (`SetWindowLong` с `GWL_EXSTYLE`). Клики и скролл проходят сквозь к игре. При наведении курсора текст плавно становится ярче (opacity с 0.7 до 1.0) и рядом появляются секунды.

> **Примечание:** WS_EX_TRANSPARENT не даёт WPF получать MouseEnter. Для hover-эффекта можно использовать polling `GetCursorPos` + hit-test, или упростить в v1 — показывать секунды всегда. Решение на этапе разработки.

### OVR-03: Позиция и drag-and-drop
В главном окне на вкладке «Отображение» — превью экрана (прямоугольник с пропорциями монитора). Пользователь перетаскивает маркер таймера внутри превью. Координаты сохраняются в `settings.json` как процент от ширины/высоты экрана. После запуска таймера позиция зафиксирована.

### OVR-04: Кастомизация внешнего вида
Настраиваемые параметры (все без пароля, меняются на лету):

| Параметр | Диапазон | По умолчанию |
|---|---|---|
| Размер шрифта | 12–72 px | 24 px |
| Прозрачность | 20–100% | 70% |
| Фон за текстом | Вкл / Выкл | Вкл (полупрозрачный) |
| Позиция | Drag в превью | Правый верхний угол |

## 04. Цветовая индикация

Цвет текста оверлея меняется в зависимости от оставшегося времени. Пороги и цвета настраиваются.

- 🟢 **Зелёный** — более 30 минут (по умолчанию `#4CAF50`)
- 🟡 **Жёлтый** — 30 минут и менее (по умолчанию `#FFC107`)
- 🔴 **Красный** — 10 минут и менее (по умолчанию `#F44336`)

### CLR-01: Настройка порогов
Два числовых поля: «Жёлтый с» (минуты, по умолчанию 30) и «Красный с» (минуты, по умолчанию 10). Валидация: жёлтый > красный > 0.

### CLR-02: Настройка цветов
Три ColorPicker для выбора цветов каждой зоны.

---

## 05. Звуковые уведомления

### SND-01: Точки уведомлений
По умолчанию звук воспроизводится на отметках: 10 минут, 2 минуты, 1 минута до таймера. Каждая точка — отдельная строка в настройках. Можно удалить существующую или добавить новую. Каждую точку можно включить/выключить индивидуально.

### SND-02: Звуковые файлы
По умолчанию — встроенный wav-файл в ресурсах приложения (мягкий короткий звук). В настройках — возможность выбрать свой wav-файл через диалог открытия файла. Воспроизведение через `System.Media.SoundPlayer`. Кнопка «Прослушать» рядом с выбранным файлом.

### SND-03: Визуальное усиление при уведомлении
В момент звукового уведомления оверлей кратковременно (2–3 секунды) увеличивает яркость и масштаб текста (пульсация), затем возвращается к нормальному виду.

## 06. Защита паролем

### SEC-01: Защищённые действия
Пароль требуется для:
- Остановки или сброса активного таймера
- Изменения времени таймера
- Изменения действия по истечении
- Закрытия приложения (кнопка X и трей-меню «Выход»)

Без пароля доступны: все визуальные и UX-настройки (размер, цвет, позиция, звуки, пороги).

### SEC-02: Реализация пароля
Захардкоженный пароль в коде (константа). При попытке защищённого действия — модальный диалог с `PasswordBox`. Три неудачные попытки — блокировка на 30 секунд. Пароль задаётся на этапе разработки.

> **На будущее (не в v1):** Интеграция с Windows-пин через `CredUI` / `LogonUser` API.

### SEC-03: Защита от закрытия процесса
Скрытие из панели задач (`ShowInTaskbar=False` для оверлея). Приложение не появляется в Alt+Tab. Имя процесса — нейтральное. Закрытие через диспетчер задач — принимаемый риск для v1.

## 07. Интерфейс главного окна

Компактное окно с табами. Минималистичный интерфейс. Фиксированный размер окна.

Вкладки: **Таймер** | **Отображение** | **Уведомления** | **Настройки**

### UI-01: Вкладка «Таймер»
Переключатель режима (абсолютное время / интервал). Поля ввода времени. Кнопки «Старт», «Стоп», «Сброс». Текущее состояние таймера. Оставшееся время крупным шрифтом если таймер активен.

### UI-02: Вкладка «Отображение»
Превью монитора с перетаскиваемым маркером позиции. Ползунок размера шрифта (live-превью). Ползунок прозрачности. Переключатель фона. Цветовые настройки зон. Настройка порогов. Все изменения применяются мгновенно.

### UI-03: Вкладка «Уведомления»
Список точек уведомлений с чекбоксами. Кнопки «Добавить» / «Удалить». Выбор звукового файла. Кнопка «Прослушать».

### UI-04: Вкладка «Настройки»
Выбор действия по истечении (ComboBox). Этот раздел защищён паролем.

## 08. Технические детали

| Компонент | Технология | Примечание |
|---|---|---|
| Framework | .NET 8 LTS | Долгосрочная поддержка |
| UI | WPF | Нативная прозрачность окон |
| Таймер | DispatcherTimer | Тик каждую секунду |
| Звук | System.Media.SoundPlayer | Встроенный в .NET |
| Click-through | SetWindowLong + WS_EX_TRANSPARENT | Win32 interop / P/Invoke |
| Topmost | WPF Topmost=True | Для borderless fullscreen |
| Alt+Tab скрытие | WS_EX_TOOLWINDOW | Win32 extended style |
| Настройки | System.Text.Json | JSON рядом с exe |
| Shutdown | Process.Start | shutdown.exe /s, /l или LockWorkStation |
| Трей | System.Windows.Forms.NotifyIcon | Ссылка на WinForms для иконки |

### TECH-01: Совместимость с полноэкранными играми
v1.0 поддерживает **borderless fullscreen** (оконный без рамки). Exclusive fullscreen (DirectX/Vulkan) не поддерживается. Рекомендация: переключить игру в borderless режим.
