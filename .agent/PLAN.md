## Этапы реализации

### Этап 1: Скаффолд и модель данных
- Создать .NET 8 WPF проект
- `AppSettings.cs` — класс с полями для всех настроек:
  - Позиция оверлея (X%, Y%)
  - Размер шрифта, прозрачность, фон вкл/выкл
  - Цвета трёх зон + пороги в минутах
  - Список точек уведомлений (минуты + вкл/выкл)
  - Путь к wav-файлу (null = встроенный)
  - Выбранное действие (enum: Shutdown, Lock, Logoff)
- `SettingsService.cs` — загрузка/сохранение JSON рядом с exe
- Константа пароля

### Этап 2: Оверлей
- `OverlayWindow.xaml` — безрамочное прозрачное окно
  - WindowStyle=None, AllowsTransparency=True, Background=Transparent
  - Topmost=True, ShowInTaskbar=False
  - TextBlock с временем (моноширинный шрифт)
  - Полупрозрачный фон-подложка за текстом (Border с скруглением)
- `NativeHelper.cs` — P/Invoke обёртки:
  - SetWindowLong для WS_EX_TRANSPARENT (click-through)
  - SetWindowLong для WS_EX_TOOLWINDOW (скрытие из Alt+Tab)
  - Применяются в OnSourceInitialized
- Анимация пульсации (Storyboard: ScaleTransform + Opacity, 2–3 сек)

### Этап 3: Логика таймера
- `TimerService.cs`:
  - DispatcherTimer с тиком 1 секунда
  - Вычисление оставшегося времени (DateTime целевое — DateTime.Now)
  - Событие Tick → обновление оверлея (текст + цвет по порогам)
  - Событие AlertTriggered → при достижении точки уведомления
  - Событие TimerExpired → при достижении нуля
- `ShutdownService.cs`:
  - Метод Execute(ActionType) — Process.Start для shutdown/lock/logoff
  - Метод CancelShutdown() — shutdown /a

### Этап 4: Звук
- `SoundService.cs`:
  - Воспроизведение встроенного wav из ресурсов (embedded resource)
  - Воспроизведение пользовательского wav по пути
  - Метод PlayAlert() — вызывается TimerService при AlertTriggered
- Генерация простого wav программно (синусоида 800Hz, 300ms)
  или включение готового файла в ресурсы

### Этап 5: Главное окно — вкладка «Таймер»
- Переключатель режима (RadioButton: абсолютное / интервал)
- Поля ввода времени (динамически по режиму)
- Кнопки Старт / Стоп / Сброс
- Стоп и Сброс → вызов PasswordDialog
- Отображение статуса и оставшегося времени

### Этап 6: Главное окно — вкладка «Отображение»
- Превью монитора (Canvas с пропорциями экрана)
  - Маркер таймера (перетаскиваемый Thumb / элемент с MouseDrag)
  - Позиция → процент от ширины/высоты → в настройки
- Ползунок размера шрифта (Slider 12–72)
- Ползунок прозрачности (Slider 20–100)
- ToggleButton фон за текстом
- Три ColorPicker (простой вариант: набор предустановленных цветов
  или TextBox с hex + превью)
- Два NumberBox для порогов (жёлтый / красный, минуты)
- Все изменения → мгновенно на оверлей + автосохранение

### Этап 7: Главное окно — вкладка «Уведомления»
- ListBox/ItemsControl с точками уведомлений
  - Каждая строка: CheckBox + значение в минутах
- Кнопка «Добавить» → поле ввода минут
- Кнопка «Удалить» → удаление выбранной
- Выбор wav-файла (кнопка → OpenFileDialog, фильтр *.wav)
- Кнопка «Прослушать» → SoundService.PlayAlert()

### Этап 8: Главное окно — вкладка «Настройки»
- ComboBox действия (Выключение / Блокировка / Выход)
- При изменении → PasswordDialog
- Информационный текст о текущем действии

### Этап 9: Трей и защита
- NotifyIcon (System.Windows.Forms.NotifyIcon)
  - Иконка в трее при сворачивании
  - Контекстное меню: «Открыть», «Выход» (с паролем)
- Перехват закрытия окна (OnClosing):
  - Если таймер активен → сворачивание в трей
  - Кнопка X → PasswordDialog → если пароль верный → закрытие
- `PasswordDialog.xaml`:
  - PasswordBox + кнопки OK/Отмена
  - Счётчик неудачных попыток → блокировка 30 сек

### Этап 10: Финализация
- Тестирование всех сценариев на Windows
- Нейтральное имя процесса в .csproj (AssemblyName)
- Проверка click-through поверх игры (borderless fullscreen)
- Первый коммит с рабочей версией

## Зависимости между этапами

```
Этап 1 (модель) ──┬── Этап 2 (оверлей) ──┐
                   │                       ├── Этап 5 (таб «Таймер»)
                   ├── Этап 3 (таймер) ────┤
                   │                       ├── Этап 6 (таб «Отображение»)
                   ├── Этап 4 (звук) ──────┤
                   │                       ├── Этап 7 (таб «Уведомления»)
                   │                       │
                   │                       ├── Этап 8 (таб «Настройки»)
                   │                       │
                   └───────────────────────┴── Этап 9 (трей + защита)
                                               │
                                               └── Этап 10 (финализация)
```

Этапы 2, 3, 4 можно разрабатывать параллельно после этапа 1.
Этапы 5–8 (вкладки UI) зависят от сервисов (этапы 2–4).
Этап 9 объединяет всё. Этап 10 — полировка.

## Открытые вопросы (решаются при разработке)

1. **Hover на click-through оверлее** — polling GetCursorPos или всегда показывать секунды в v1?
2. **ColorPicker** — нативного в WPF нет. Варианты: набор предустановленных цветов (простой), TextBox с hex-вводом + цветной превью (средний), или сторонний контрол. Рекомендация для v1: предустановленные + hex-ввод.
3. **Wav-файл** — сгенерировать программно при первом запуске или включить бинарный ресурс? Рекомендация: генерация программно (нет зависимости от файла).
